# Veadicare Welcome Page

Temporary launch / welcome page for Veadicare.

## Stack
- React
- Vite
- CSS
- Lucide React

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Build

```bash
npm run build
```

## Deploy

The project can be deployed to Vercel and then connected to `veadicare.in`.

> Note: the email form is currently UI-only. It does not store email addresses until a backend/email provider is intentionally added.
